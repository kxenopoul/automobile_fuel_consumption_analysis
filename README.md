### Περιγραφή

Στο project αυτό αναλύουμε δεδομένα 398 αυτοκινήτων με τη χρήση Python.

Σκοπός είναι να εξετάσουμε πώς χαρακτηριστικά όπως το βάρος, η ιπποδύναμη, ο κυβισμός και ο αριθμός κυλίνδρων σχετίζονται με την κατανάλωση καυσίμου.

Επίσης, χρησιμοποιούμε διαφορετικά μοντέλα παλινδρόμησης για την πρόβλεψη της κατανάλωσης σε L/100km και συγκρίνουμε την απόδοσή τους.

### Μαθησιακή Προσέγγιση

Το project αναπτύχθηκε στο πλαίσιο της προσωπικής μου εκμάθησης Data Analysis και Machine Learning, αξιοποιώντας ως εκπαιδευτική βάση το υλικό και τις ασκήσεις του προγράμματος IBM Data Science Professional Certificate στο Coursera.

Κατά τη διάρκεια της ανάπτυξης χρησιμοποιήθηκε επίσης Τεχνητή Νοημοσύνη ως βοηθητικό εργαλείο για καθοδήγηση, επεξήγηση εννοιών, εντοπισμό λαθών και αξιολόγηση του κώδικα.

Βασική μου επιδίωξη ήταν να γράφω προσωπικά τον κώδικα, να κατανοώ όσο το δυνατόν καλύτερα τη λειτουργία κάθε γραμμής και να αναπτύσσω σταδιακά την ικανότητα ανεξάρτητης επίλυσης προβλημάτων.

Το project αποτελεί μια προσωπική μαθησιακή προσπάθεια, με έμφαση στην πρακτική εφαρμογή των γνώσεων και στη σταδιακή ανάπτυξη δεξιοτήτων ανάλυσης δεδομένων.

### Εργαλεία

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn και Jupyter Notebook.

### Τι έχει ολοκληρωθεί

- Φόρτωση και αρχικός έλεγχος δεδομένων.
- Data Cleaning και αντικατάσταση ελλιπών τιμών.
- Μετατροπή MPG σε L/100km και lbs σε kg.
- Ανάλυση συσχετίσεων μεταξύ μεταβλητών.
- Οπτικοποίηση δεδομένων με Regplot, Boxplot και Heatmap.
- Εφαρμογή Simple Linear Regression.
- Διαχωρισμός δεδομένων σε Training και Test Sets.
- Εφαρμογή Multiple Linear Regression με διαφορετικές ανεξάρτητες μεταβλητές.
- Εφαρμογή Polynomial Regression.
- Χρήση Pipelines με PolynomialFeatures, StandardScaler και Ridge Regression.
- Βελτιστοποίηση υπερπαραμέτρων με GridSearchCV και 5-Fold Cross-Validation.
- Αξιολόγηση και σύγκριση μοντέλων με R² και MSE.
- Ανάλυση τυποποιημένων συντελεστών γραμμικής παλινδρόμησης.
- Σύγκριση πραγματικών και προβλεπόμενων τιμών.
- Ανάλυση υπολοίπων (Residual Analysis) και εντοπισμός των μεγαλύτερων σφαλμάτων πρόβλεψης.
- Εξαγωγή τελικών συμπερασμάτων και αναφορά στους περιορισμούς της ανάλυσης.

### Αποτελέσματα

Η ανάλυση έδειξε ισχυρή θετική συσχέτιση μεταξύ της κατανάλωσης καυσίμου και χαρακτηριστικών όπως το βάρος, η ιπποδύναμη και ο κυβισμός.

Επιπλέον, παρατηρήθηκαν υψηλές συσχετίσεις μεταξύ αρκετών ανεξάρτητων μεταβλητών, γεγονός που αποτελεί ένδειξη πολυσυγγραμμικότητας.

Από τη σύγκριση των μοντέλων προέκυψαν τα παρακάτω αποτελέσματα:

| Μοντέλο | Cross-Validation R² | Test R² |
|---|---|---|
| Simple Linear Regression (Weight) | 0.774 | 0.871 |
| Multiple Linear Regression (4 μεταβλητές) | 0.798 | 0.882 |
| Multiple Linear Regression (όλες οι μεταβλητές) | 0.875 | 0.923 |
| Polynomial Ridge Regression | 0.895 | 0.933 |

Το Polynomial Ridge Regression παρουσίασε την καλύτερη συνολική απόδοση στη συγκεκριμένη σύγκριση.

Η αναζήτηση υπερπαραμέτρων με GridSearchCV οδήγησε στα παρακάτω αποτελέσματα:

- Best Polynomial Degree: 4
- Best Alpha: 0.788
- Cross-Validation R²: 0.895
- Test R²: 0.933
- Test MSE: 0.927
- Test RMSE: 0.963 L/100km

### Τελικά Συμπεράσματα

Η προσθήκη περισσότερων χαρακτηριστικών βελτίωσε την προβλεπτική απόδοση των μοντέλων σε σχέση με την αρχική γραμμική παλινδρόμηση που χρησιμοποιούσε μόνο το βάρος.

Η εφαρμογή Polynomial Ridge Regression παρουσίασε επιπλέον βελτίωση, επιτυγχάνοντας το υψηλότερο μέσο R² στο Cross-Validation.

Από την ανάλυση των πραγματικών και προβλεπόμενων τιμών παρατηρήθηκε ότι οι περισσότερες προβλέψεις βρίσκονται κοντά στις πραγματικές καταναλώσεις. Η ανάλυση των υπολοίπων δεν ανέδειξε κάποιο έντονο συστηματικό μοτίβο, αν και εντοπίστηκαν ορισμένα αυτοκίνητα με μεγαλύτερα σφάλματα.

Παρά τα θετικά αποτελέσματα, υπάρχουν περιορισμοί. Το dataset είναι σχετικά μικρό, ενώ η αρχική αντικατάσταση των ελλιπών τιμών πραγματοποιήθηκε πριν από τον διαχωρισμό των δεδομένων, κάτι που μπορεί να επηρεάσει την αξιολόγηση.

Συνολικά, το project αποτέλεσε μια πρώτη ολοκληρωμένη προσπάθεια εφαρμογής τεχνικών Data Analysis και Machine Learning, από την αρχική επεξεργασία δεδομένων μέχρι την εκπαίδευση, τη βελτιστοποίηση και την αξιολόγηση μοντέλων.
