# Αναλυση Δεδομενων Αυτοκινητων και Προβλεψη Καταναλωσης Καυσιμου

### Περιγραφη

Στο project αυτο αναλυουμε δεδομενα 398 αυτοκινητων με τη χρηση Python.

Σκοπος ειναι να εξετασουμε πως χαρακτηριστικα οπως το βαρος, η ιπποδυναμη, ο κυβισμος και ο αριθμος κυλινδρων σχετιζονται με την καταναλωση καυσιμου.

Επισης, χρησιμοποιουμε διαφορετικα μοντελα παλινδρομησης για την προβλεψη της καταναλωσης σε L/100Km και συγκρινουμε την αποδοση τους.

### Μαθησιακη Προσεγγιση

Το project αναπτυσσεται στο πλαισιο της προσωπικης μου εκμαθησης Data Analysis και Machine Learning, αξιοποιωντας ως εκπαιδευτικη βαση το υλικο και τις ασκησεις του προγραμματος IBM Data Science Professional Certificate στο Coursera. Κατα τη διαρκεια της αναπτυξης χρησιμοποιειται επισης Τεχνητη Νοημοσυνη ως βοηθητικο εργαλειο για καθοδηγηση, επεξηγηση εννοιων, εντοπισμο λαθων και αξιολογηση του κωδικα. Βασικη μου επιδιωξη ειναι να γραφω προσωπικα τον κωδικα, να κατανοω οσο το δυνατον καλυτερα τη λειτουργια καθε γραμμης και να αναπτυσσω σταδιακα την ικανοτητα ανεξαρτητης επιλυσης προβληματων. Το project αποτελει μια προσωπικη μαθησιακη προσπαθεια, με εμφαση στην πρακτικη εφαρμογη των γνωσεων και στη βαθμιαια αναπτυξη δεξιοτητων αναλυσης δεδομενων.

### Εργαλεια

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn και Jupyter Notebook.

### Τι εχει ολοκληρωθει

- Φορτωση και αρχικος ελεγχος δεδομενων.
- Data Cleaning και αντικατασταση ελλιπων τιμων.
- Μετατροπη MPG σε L/100Km και lbs σε kg.
- Αναλυση συσχετισεων μεταξυ μεταβλητων.
- Οπτικοποιηση δεδομενων με Regplot και Boxplot.
- Εφαρμογη Simple Linear Regression.
- Διαχωρισμος δεδομενων σε Training και Test Sets.
- Εφαρμογη Multiple Linear Regression με διαφορετικες ανεξαρτητες μεταβλητες.
- Εφαρμογη Polynomial Regression.
- Χρηση Pipelines με PolynomialFeatures, StandardScaler και Ridge Regression.
- Βελτιστοποιηση υπερπαραμετρων με GridSearchCV και 5-Fold Cross-Validation.
- Αξιολογηση μοντελων με R² και MSE σε Training και Test Sets.

### Αποτελεσματα

Η αναλυση εδειξε ισχυρη θετικη συσχετιση μεταξυ της καταναλωσης καυσιμου και χαρακτηριστικων οπως το βαρος, η ιπποδυναμη και ο κυβισμος.

Στο Polynomial Ridge Regression, η αναζητηση υπερπαραμετρων με GridSearchCV οδηγησε στα παρακατω αποτελεσματα:

- Best Polynomial Degree: 4
- Best Alpha: 0.788
- Cross-Validation R²: 0.895
- Test R²: 0.933
- Test MSE: 0.927

Τα αποτελεσματα αυτα αφορουν το συγκεκριμενο μοντελο και θα αξιολογηθουν συνολικα πριν την τελικη επιλογη.

Citation: Quinlan, R. (1993). Auto MPG. UCI Machine Learning Repository.
